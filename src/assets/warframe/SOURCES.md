# Warframe navigation icons

These are unmodified in-game UI category textures, copyright Digital Extremes, downloaded from the [browse.wf game asset archive](https://browse.wf/Lotus/Interface/Icons/Categories/). They are bundled with the app; loading the tabs does not contact the archive.

| Local file | Original game asset |
| --- | --- |
| `weapons.png` | [IconWeapons_256.png](https://browse.wf/Lotus/Interface/Icons/Categories/IconWeapons_256.png) |
| `warframes.png` | [IconWarframe_256.png](https://browse.wf/Lotus/Interface/Icons/Categories/IconWarframe_256.png) |
| `relics.png` | [IconRelic256.png](https://browse.wf/Lotus/Interface/Icons/Categories/IconRelic256.png) |

The original alpha channels are used as CSS masks so icons inherit each tab's text color in both themes. Despite its original filename, the Warframe texture is 64 × 64 pixels; the other two are 256 × 256 pixels.
